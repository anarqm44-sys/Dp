# منصة "سهلتهالك بكالوريا" التعليمية (Saheltahalk Baccalaureate)

منصة تعليمية إلكترونية متكاملة ومصممة خصيصاً لطلاب شهادة الثانوية العامة (البكالوريا) وفق النظام الحديث.

---

## 🌟 الميزات الرئيسية

1. **نظام المصادقة وحسابات الطلاب**:
   - تسجيل حساب جديد برقم الهاتف والشعبة الدراسية (علمي علوم، علمي رياضة، أدبي).
   - رصيد ترحيبي فوري (100 ج.م) لكل طالب جديد لتجربة شراء الكورسات.
   - تسجيل الدخول الآمن برقم الهاتف وتشفير كلمات المرور بواسطة `Werkzeug`.
   - فصل كامل بين صلاحيات الطلاب ومدير المنصة (Role-Based Access Control).

2. **المناهج والكورسات والدروس**:
   - تصفح الكورسات وفلترتها بحسب المواد (اللغة العربية، اللغة الإنجليزية، التاريخ، إلخ).
   - صفحات تفصيلية لكل كورس توضح الدروس والاختبارات المرفقة وسعر الاشتراك.
   - إمكانية توفير دروس بمعاينة مجانية لجميع الزوار.
   - مشغل فيديو مدمج وملاحظات مع إمكانية إرفاق وتحميل مذكرات بصيغة PDF.

3. **بنك الاختبارات والتصحيح التلقائي الفوري**:
   - اختبارات دورية وشاملة موقوتة بمؤقت زمني تنازلي وتنبيه عند انتهاء الوقت.
   - تصحيح إلكتروني ذكي فوري بمجرد تسليم الإجابات.
   - صفحة نتائج تفصيلية توضح النسبة المئوية، مقارنة إجابة الطالب بالإجابة الصحيحة، والتعليل والتفسير العلمي لكل سؤال.

4. **المحفظة الإلكترونية وشحن الرصيد**:
   - عرض رصيد المحفظة الحي في شريط التصفح العلوي.
   - إمكانية طلب شحن المحفظة عبر فودافون كاش، أورنج كاش، اتصالات كاش، وإنستاباي (InstaPay).
   - نظام مراجعة واعتماد طلبات الشحن من لوحة الإدارة بضغطة زر واحدة.
   - شراء الكورسات مباشرة بالخصم من رصيد المحفظة.

5. **منتدى النقاش العلمي**:
   - منتدى مفتوح لتبادل الأسئلة والاستفسارات بين الطلاب والمعلمين.
   - تصنيف الأسئلة حسب المواد الدراسية.
   - إمكانية إضافة إجابات وردود مع شارات تمييز خاصة بالمعلمين والإدارة.

6. **لوحة تحكم شاملة للمدير (Admin Dashboard)**:
   - إحصائيات عامة (عدد الطلاب، الكورسات، الاختبارات، الطلبات المعلقة).
   - إدارة الكورسات والدروس (إضافة، تعديل، حذف، تغيير السعر، النشر).
   - إدارة الاختبارات وبنك الأسئلة مع الشروحات والدرجات.
   - مراجعة طلبات الشحن (اعتماد / رفض مع تحديث الرصيد التلقائي).
   - إدارة الطلاب وحساباتهم وتعديل أرصدة المحافظ وتنشيط أو تعطيل الحسابات.

7. **تصميم واجهة المستخدم**:
   - واجهة عربية أصيلة بنسبة 100% مع تخطيط من اليمين لليسار (RTL).
   - خط "Cairo" العربي مع ألوان الهوية الزرقاء الاحترافية (`#2563EB`).
   - متجاوبة بالكامل مع الهواتف الذكية والأجهزة اللوحية وأجهزة الكمبيوتر.

## 🚀 التشغيل المحلي (Local Development)

### 1. تشغيل التطبيق:
```powershell
py app.py
```
أو:
```powershell
python app.py
```

### 2. فتح المنصة في المتصفح:
افتح المتصفح على العنوان التالي:
[http://localhost:5000](http://localhost:5000)

---

## ⚙️ التجهيز للإنتاج (Production & PostgreSQL)

التطبيق مهيأ بالكامل للرفع على استضافات مثل **Render** أو **Railway** أو **VPS**:
- يدعم التبديل إلى **PostgreSQL** عن طريق المتغير البيئي `DATABASE_URL`.
- يدعم خادم الإنتاج `gunicorn`:
  ```bash
  gunicorn app:app
  ```
